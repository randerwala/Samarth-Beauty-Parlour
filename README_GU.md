ગુજરાતી બ્યુટી પાર્લર Android એપ — સોર્સ પ્રોજેક્ટ

સુવિધાઓ:
- બુકિંગ ઉમેરવું અને ગ્રાહકની યાદી/શોધ
- સર્વિસ અને ભાવ મેનેજ કરવું
- ચુકવણી નોંધવી, આવક અને બાકી રકમ જોવી
- CSV રેકોર્ડ એક્સપોર્ટ
- ઓફર બનાવવી અને શેર કરવી
- માહિતી આ Android ડિવાઇસના WebView localStorage માં રહે છે

APK બનાવવા:
1. Android Studio (Giraffe અથવા નવું) ઇન્સ્ટોલ કરો.
2. આ ZIP extract કરો અને Android Studio માં ફોલ્ડર ખોલો.
3. Gradle sync પૂર્ણ થવા દો (JDK 17 જરૂરી).
4. Build > Build APK(s) પસંદ કરો.
5. APK સામાન્ય રીતે app/build/outputs/apk/debug/app-debug.apk માં મળશે.

મર્યાદા:
આ પ્રારંભિક આવૃત્તિ છે. ગ્રાહકોના અલગ ફોનથી સીધું ઓનલાઇન બુકિંગ/સિંક કરવા માટે સર્વર અથવા Firebase અને પ્રકાશિત વેબ/Play Store સેટઅપ ઉમેરવું પડશે. હાલના રેકોર્ડ ફક્ત આ ફોન/એપના સ્ટોરેજમાં રહે છે. એપ uninstall અથવા app data clear કરવાથી રેકોર્ડ ગુમાઈ શકે છે; સમયાંતરે CSV export રાખો.
